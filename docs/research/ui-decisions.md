Nielsen Norman Group의 progressive disclosure 페이지는 프록시가 차단하여 원문을 확인하지 못했고, 검증한 근거로 인용하지 않았습니다. 외부 지침만으로 사용성이나 WCAG 전체 준수를 보증하지 않습니다. 320px 화면/키보드 테스트와 스크린샷을 함께 확인합니다.

## 시각 체계

- 흰 배경, 중립 회색, 한 종류의 주요 버튼. 영어 슬로건·장식용 배지·중복 안내 제거.
- 현재 대화를 자동으로 읽고 질문을 먼저 표시. 참가 AI 변경과 검토 깊이는 접힌 설정에 배치. 선택은 `aria-pressed`, 원래 메인 대화로 돌아가는 기능은 그대로 유지.
- 공급자 로고는 `@lobehub/icons-static-svg@1.95.1`의 OpenAI 매듭, Claude 별 모양, Gemini 컬러 별 SVG를 원본 그대로 로컬 번들에 포함. 문자 G/C/별표 대체 아이콘을 제거. 원격 이미지를 로드하지 않음.
- 아이콘에는 옆의 공급자 이름과 중복되지 않도록 빈 alt를 사용. 기존의 문자 아이콘이 heading 이름에 섞이던 접근성 문제도 수정.
- 모델 답변과 출처는 실제 데이터이므로 필요한 순간 펼쳐 볼 수 있게 하되, 최종 답변은 그대로 표시.

0.2.0에서는 단계별 승인과 수동 전달을 기본 경로에서 제거했습니다. 자동 감지된 질문, 참여 AI, 시작 버튼이 기본 화면입니다. 질문 복사/답변 붙여넣기는 실패 후 복구 안에서만 표시합니다. 최종 답변과 원래 메인 대화로 이동은 완료 시 바로 표시합니다.
