# 실제 로그인 E2E — 터미널 없이

실제 설치된 사이드패널과 같은 Chrome 프로필의 로그인 서비스를 사용합니다. 비밀번호·쿠키·토큰을 개발자에게 보내지 마세요. 자동화 허용 근거와 공개 배포 조건은 [출시 체크리스트](../release/release-checklist.md)에서 별도로 확인합니다.

## 검증 근거

버전별 실제 결과와 남은 제한은 [검증 기록](validation.md)에 기록합니다. 아래 절차는 실행 체크리스트이며, 항목이 있다는 사실은 통과 근거가 아닙니다. 단위·합성 브라우저·설치 확장·실계정 결과를 구분하세요.

## 준비와 시작

개발자 모드 확장을 허용하는 Chrome 120 이상에서 같은 프로필로 사용할 서비스에 로그인합니다. 새로 설치하거나 교체했다면 설치 폴더와 빌드 manifest의 버전, 실제 사이드패널을 확인하고 기존 AI 탭을 새로고침합니다. 비로그인 상태에서의 전체 인증 과정은 기존 로그인 계정 검사와 별도로 기록합니다. 새롭고 민감하지 않은 테스트 대화와 합성 파일을 사용하세요.

- [ ] 메인 대화에 짧은 테스트 질문을 보내고, 앞선 내용을 참조하는 후속 질문을 이어서 적어도 세 쌍을 완성합니다. 파일 검증에는 내용을 알고 있는 합성 TXT·PNG 원본을 같은 질문에 첨부합니다.
- [ ] 패널의 **현재 탭에서 가져오기**(원본이 있으면 **현재 탭으로 변경**)로 필요한 사이트 권한을 허용하고 실제 쌍 수와 모든 질문·답변을 펼쳐 확인합니다. 읽기가 실패하거나 답변이 미완성이면 시작하지 않습니다.
- [ ] **파일 선택**에서 해당 대화의 파일·이미지 원본을 모두 선택합니다. 최대 10개·합계 20 MB이며 사이트별 제한도 적용됩니다. 원본이 없으면 첨부가 없는 대화를 사용합니다.
- [ ] 선택된 파일을 확인한 뒤 **원래 대화의 파일·이미지를 모두 선택했습니다**를 체크합니다. 파일이 없는 테스트에서는 **원래 대화에 첨부파일이 없습니다**를 체크합니다. 기존 대화의 첨부를 확장이 자동 다운로드한다고 가정하지 않습니다.
- [ ] **검토할 다른 AI**에서 한 개 이상 고릅니다. 원본 메인은 자동으로 포함됩니다. **연결**에서 사용할 AI를 연결하고, 새 탭에서 로그인이 필요하면 직접 로그인한 뒤 **로그인 완료 · 다시 확인**을 누릅니다.
- [ ] 다른 AI 탭을 열어도 고정한 메인 질문·답변은 바뀌지 않습니다. **원래 대화로 돌아가기**로 원래 대화를 확인합니다. 원본을 바꾸려는 경우에만 **현재 탭으로 변경**을 사용합니다.
- [ ] **자동 검토 시작**을 한 번 누르고 패널을 열어둡니다. 원래 메인 답변을 재사용하며 중간 단계 승인이나 복사·붙여넣기는 필요하지 않습니다.

## 전송과 최종 수집

- [ ] 각 AI의 첫 요청에 선택한 원본 파일이 동일하게 전달되고 업로드 준비를 확인한 뒤 질문이 전송됩니다. 빠르게 모드의 메인에는 최종 종합 요청 때 처음 전달됩니다.
- [ ] 업로드 실패가 파일 없는 질문으로 조용히 바뀌지 않습니다. Claude의 문단 줄바꿈과 Gemini의 중첩 파일 입력란이 실제 화면에서 정상 처리되는지 확인합니다.
- [ ] 다른 AI의 첫 요청에 앞선 모든 불러온 질문·답변 쌍이 들어가는지 확인하고 해당 질문의 완료 답변을 수집합니다. 확장이 새 대화에 첫 질문을 보내면서 생기는 주소 변경만 허용하고, 이후 임의의 대화 변경은 거부합니다.
- [ ] 추가 클릭 없이 교차 검토하고 수집한 답변과 비판이 최종 프롬프트에 포함됩니다. 이후 같은 AI의 검토 요청에 원본 파일을 반복 첨부하지 않습니다.
- [ ] 최종 프롬프트가 **원래 고정한 메인 대화**에 전송되고 완료된 최종 답변이 실제 사이드패널에 표시됩니다. 일반 탭의 테스트 패널이나 수동 스크립트 주입으로 이 항목을 대신하지 않습니다.
- [ ] 웹 검색 실행은 사이트 화면에서 별도로 확인합니다. 출처 원문과 주장 일치도는 다시 검증하며 모델 간 합의를 사실 검증으로 표시하지 않습니다.

## 연결·실패·복원

- [ ] 원본의 이전 턴을 수정하거나 별도 턴을 추가하면 최종 전송을 막습니다. 원본 메인이나 저장된 다른 AI 대화를 임의로 다른 주소로 바꾸거나 새로고침하면 추가 전송이 차단됩니다. 패널 열기·포커스 검사는 저장된 주소·문서 신원을 검사할 뿐 자동 재연결하지 않습니다.
- [ ] 명시적인 **연결** 또는 **로그인 완료 · 다시 확인**으로 새로 연결할 수 있으나, 이미 시작한 검토를 다른 대화로 조용히 옮기지 않습니다.
- [ ] 작성 중인 메시지를 덮어쓰지 않습니다. 모호한 입력란·완료 여부·업로드 상태·전송 여부에서는 중단하고, 로그인·한도·CAPTCHA를 우회하지 않습니다.
- [ ] 실패한 업로드나 전송 여부가 불확실한 요청을 자동 재시도하지 않습니다. 패널 종료/검토 중단 후 다시 열어도 자동 재전송하지 않습니다.
- [ ] 패널을 다시 열어 계속하려면 같은 원본 파일을 다시 선택해야 합니다. 이름·형식·크기·SHA-256이 맞지 않거나 파일이 누락되면 추가 전송 전에 거부합니다. 원본 바이트는 패널 메모리에만 있고 세션에는 메타데이터만 저장됩니다.
- [ ] **연결**에서 AI별 검사와 모델 목록 새로고침이 됩니다. 목록은 해당 계정의 실제 웹 선택지와 일치하며 모델 변경 과정에서 질문을 보내지 않습니다.
- [ ] 모델 선택 후 실제 웹 표시도 바뀝니다. 업그레이드/사용 불가 모델을 클릭하지 않으며, 메뉴 미지원이면 웹의 현재 모델을 유지한다고 안내합니다. 없는 모델·구독 권한·잔여 쿼타를 추측하지 않습니다.

## 업데이트와 기록

- [ ] 패널 하단에 실제 설치 버전과 설치 방식에 맞는 업데이트 안내가 표시됩니다. 설치 버전만으로 최신 버전이라고 판단하지 않습니다.
- [ ] 스토어 설치본은 Chrome 자동 업데이트를 사용하고 압축해제 설치본은 새 빌드로 수동 교체합니다. 진행 중 강제 새로고침하지 않습니다. 업데이트 알림이 있으면 검토를 마치고 **기록 저장** 후 패널을 닫습니다.
- [ ] 확장 비활성화·새로고침·업데이트·브라우저 재시작 뒤 세션 기록과 연결이 사라집니다. 필요한 기록을 먼저 저장하고 이후 새 검토로 시작합니다. 파일 재선택만으로 업데이트 전 검토를 복원할 수 있다고 안내하지 않습니다. AI 사이트에 보낸 대화와 내려받은 기록은 별도로 남습니다.

오류 재현에는 **연결 → 진단 저장**을 사용할 수 있습니다. 진단은 입력란 여부·레이아웃·메시지 수 등 구조 정보만 포함하며 질문/답변/URL/계정 식별자는 포함하지 않습니다. 날짜, 확장·Chrome 버전, OS, UI 언어, 실패 단계와 위 네 종류의 검증 근거를 구분해 기록하세요. 개인 대화나 계정 화면을 공개 로그·스크린샷에 넣지 마세요.
