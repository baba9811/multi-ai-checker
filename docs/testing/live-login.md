# 실제 로그인 E2E — 터미널 없이

실계정 검증은 아래 절차로 진행합니다. 합성 fixture 테스트와 구분하며, 아직 실계정 검증 완료로 표시하지 않았습니다. 비밀번호·쿠키·토큰을 개발자에게 보내지 마세요.

개발자 모드 확장을 허용하는 개인 Chrome 120 이상에서 같은 프로필로 사용할 서비스에 로그인합니다. 업데이트한 경우 확장과 AI 탭을 모두 새로고침합니다. 테스트용 대화를 사용합니다.

- [ ] ChatGPT에 “물은 언제나 100°C에서 끓나요? 조건과 근거를 알려주세요.”를 묻습니다.
- [ ] 패널에 현재 질문과 답변이 자동으로 표시됩니다. 첫 권한 허용 전에는 시작 후 읽을 수 있습니다.
- [ ] **자동 검토 시작** 한 번으로 선택한 사이트의 권한을 요청하고, 이미 있는 메인 답변을 재사용합니다.
- [ ] 다른 AI에 각각 한 번 질문을 보내고 답변을 수집합니다. 새 대화 생성 시 주소가 바뀌어도 다음 검토가 진행됩니다.
- [ ] 추가 클릭 없이 답변들을 교차 검토하고 그 비판이 최종 프롬프트에 포함됩니다.
- [ ] 최종 프롬프트가 **원래 메인 대화**에 전송되고 완성된 최종 답변이 패널에 표시됩니다.
- [ ] 웹 검색을 실제 사용했는지 사이트 화면에서 확인합니다. 출처 원문과 주장 일치도는 별도로 확인합니다.
- [ ] 메인 대화를 다른 주소로 바꾸거나 새로고침하면 추가 전송이 차단됩니다.
- [ ] 작성 중인 메시지를 덮어쓰지 않고 한도·로그인·CAPTCHA를 자동 우회하지 않습니다.
- [ ] 패널 종료/검토 중단 후 복원해도 자동 재전송하지 않습니다.
- [ ] **연결**에서 AI별 연결 검사와 모델 목록 새로고침이 됩니다. 목록은 해당 계정의 실제 웹 선택지와 같습니다.
- [ ] 모델 선택 후 실제 웹의 모델 표시도 바뀝니다. 업그레이드/사용 불가 모델은 클릭되지 않습니다. 질문 전송은 없습니다.
- [ ] 지원하지 않는 모델 메뉴는 웹의 현재 모델을 유지한다고 표시합니다. 없는 모델을 표시하지 않습니다.
- [ ] Chrome 재시작 뒤 세션 기록이 사라집니다. AI 사이트의 대화는 별도 보관됩니다.

오류 재현에 필요하면 **연결 → 진단 저장**을 사용합니다. 파일에는 입력란 여부·레이아웃·메시지 수 등이 있으며 질문/답변/URL/계정 식별자는 없습니다. 날짜, Chrome 버전, OS, UI 언어와 실패한 단계만 함께 기록하세요.
