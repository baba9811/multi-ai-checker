# 보안과 개인정보

## 권한과 데이터 경계

| 항목           | 동작                                                                                |
| -------------- | ----------------------------------------------------------------------------------- |
| `sidePanel`    | 사용자 작업 화면                                                                    |
| `storage`      | 브라우저 세션 메모리 기록. sync/local 대화 저장 없음                                |
| `scripting`    | 선택한 탭의 top frame에 로컬 bridge 주입                                            |
| `activeTab`    | 사용자가 연 확장에서 현재 탭 선택                                                   |
| Optional hosts | chatgpt.com / claude.ai / gemini.google.com의 HTTPS만, 시작 시 선택한 origin만 허용 |

쿠키·비밀번호·로그인 토큰을 조회하지 않습니다. 확장 백엔드, telemetry, 별도 개발자 API, remote code, web-accessible resource, MAIN-world 주입, `postMessage` 명령 채널이 없습니다. 확장 화면의 CSP는 외부 네트워크와 실행 코드를 막으며, 공급자 페이지에서 실행되는 bridge의 같은-origin 요청과는 구분합니다. 연결을 해제하면 해당 origin 권한을 제거합니다.

선택한 서비스에는 패널에서 공유 범위를 확인한 여러 턴의 질문과 답변·검토·근거 및 직접 선택한 원본 첨부파일을 보냅니다. 해당 서비스는 자신의 로그인 쿠키와 기존 대화 맥락을 사용하며, 그 서비스의 데이터 처리 정책이 적용됩니다. 확장은 서비스의 보관·학습 설정을 변경하지 않습니다.

첨부 원본은 열린 패널의 메모리와 전송 대상 탭의 일시적인 업로드 처리에만 사용하며 저장소에 기록하지 않습니다. 세션에는 파일 이름·크기·형식·SHA-256 확인값을 보관합니다. 기존 대화의 파일 원본이나 썸네일을 자동 수집하지 않습니다. 패널을 닫거나 새로고침한 뒤 계속하려면 같은 원본을 다시 선택해야 합니다. 전송 경계에서 개수·합계 크기·인코딩을 검사하고, 업로드 전에 원본 해시를 검증합니다. 파일 업로드 자체로 대상 AI 서비스에 데이터가 전달되므로 전송이 실패해도 업로드된 파일은 해당 서비스에 남을 수 있습니다.

## 실험용 Claude 연결 시험

이 개발 브랜치는 명시적인 **백그라운드 연결 시험**에만 Claude 내부 HTTP 경로를 사용합니다. 비활성 새 탭의 ISOLATED bridge가 `credentials: 'same-origin'`으로 요청하므로 브라우저가 인증 쿠키를 부착하며 JavaScript로 쿠키·토큰을 읽지 않습니다. 조직·모델 참조는 공급자 페이지의 일시적인 메모리 안에서만 처리하고, 확장 메시지·저장소·진단·개발자 서버로 보내지 않습니다. 기존 origin 권한을 사용하며 쿠키 조회 권한을 추가하지 않습니다.

고정된 비민감 테스트 문장 한 번과 빈 첨부 목록만 전송합니다. 채팅 capability 조직이 유일하지 않거나 실제 화면의 현재 모델을 계정 메타데이터와 유일하게 대응시키지 못하면 POST 전에 멈춥니다. API 전용 조직이나 첫 조직을 임의로 선택하지 않습니다. 임의 URL·헤더·프롬프트 대리 호출, 보안 검사 해결, 재시도, DOM 대체 전송은 없습니다. 생성 UUID 대응과 텍스트 블록 닫힘·정상 종료·최종 완료 이벤트를 모두 확인해야 완료로 표시합니다. 실패 사유는 고정된 단계값으로만 전달하며 서버 오류 원문·계정 참조·인증정보를 포함하지 않습니다.

세션에는 시험 ID와 `pending`/`done`/`uncertain` 상태만 저장하고 답변은 열린 패널 메모리에서만 표시합니다. 패널 종료·중단·새로고침 후 자동 재개하지 않습니다. 요청이 이미 처리됐거나 서버에서 계속 생성되면 시험 대화가 Claude에 남을 수 있으며 사용자가 사이트에서 확인·삭제해야 합니다. 이 시험은 기본 DOM 검토를 변경하지 않고 전체 문맥·파일·최종 반환을 검증하지 않습니다. [조사 및 검증 범위](../research/background-web-transport.md).

## 공격/오작동 방어

- 모델 출력과 페이지 텍스트는 신뢰하지 않습니다. React 텍스트로만 표시합니다. 원격 이미지·HTML·Markdown 실행을 하지 않습니다.
- 명령은 Zod 스키마, 자신의 확장 ID, 정확한 sidepanel URL로 검증합니다. 데이터로 임의 URL 탐색·스크립트·도구 호출을 실행하지 않습니다.
- 출처 링크는 공개 HTTPS 주소의 사용자 클릭만 지원합니다. IP/localhost/자격증명 포함 URL/다른 scheme/포트를 거부합니다. 링크의 진위나 DNS 안전성을 보증하지 않으며 자동 fetch하지 않습니다.
- 시작 버튼에 공유 대상과 자동 최종 요청을 안내합니다. 선택한 페이지에 불러온 완료된 여러 질문·답변 쌍을 가져오며, 개인정보가 담긴 대화의 공유 여부는 사용자가 결정합니다. 연결 메뉴의 모델 변경은 질문을 보내지 않습니다.
- 작성 중인 입력·중복 요청·응답 중인 탭·바뀐 대화·완료 미확인 답변은 안전하게 실패합니다. CAPTCHA나 rate limit을 우회하지 않습니다.
- 프롬프트 injection에 대해 JSON 데이터 경계를 명시하지만 이것은 완전한 방어가 아닙니다. 모델 출력에 브라우저/계정 권한을 주지 않는 구조가 핵심 경계입니다.

## 삭제 및 보관

Chrome `storage.session`의 검토 기록·연결 참조는 브라우저 재시작뿐 아니라 확장 비활성화·새로고침·업데이트 때도 사라집니다. 필요한 검토는 업데이트 전에 **기록 저장**으로 내려받습니다. 확장 화면의 새 검토는 질문·답변·근거를 지우고 탭 연결은 유지하며, 각 연결 카드에서 따로 권한을 해제할 수 있습니다. 이미 AI 사이트에 보낸 대화와 내보낸 파일은 별도로 삭제해야 합니다. 진단 내보내기에는 질문·답변·URL·계정값을 넣지 않습니다. [Chrome 세션 저장소 수명](https://developer.chrome.com/docs/extensions/reference/api/storage#property-session).

실험의 상태 기록에도 같은 저장소 수명이 적용됩니다. 이 문서는 개발 브랜치의 데이터 흐름을 설명하며, 이미 업로드한 스토어 패키지나 공개 개인정보처리방침을 변경했다는 뜻이 아닙니다. 이 기능을 배포하기 전 해당 공개 문서와 등록정보를 실제 패키지에 맞춰 다시 검토해야 합니다.

## 잔여 위험

실제 사이트의 UI/언어/실험군에 따라 선택자가 달라질 수 있습니다. 내부 HTTP 경로도 문서화된 호환성 계약이 아니며 계정별 모델·응답 형식 변경으로 시험이 실패할 수 있습니다. 검증 fixture는 현재 실서비스의 정확한 복제가 아닙니다. 완성 표시 감지가 보수적이어도 사이트 변화가 오탐/누락을 만들 수 있으므로 답변과 메인 탭을 확인해야 합니다. 출처가 모델의 허구일 수 있으며 합의율을 진실 확률로 제공하지 않습니다. 최신 서비스 약관과 스토어 정책 검토, 실계정 E2E는 출시 조건입니다.
