# CrossCheck · Multi AI Checker

로그인한 ChatGPT·Claude·Gemini 웹 대화의 답변을 모아 검토하고, **원래 메인 대화에 재탐색·최종 종합 프롬프트를 보내는** Chrome 사이드패널 확장입니다. 사용자는 API 키, CLI, TUI 없이 웹 로그인과 확장 화면만 사용합니다.

> **현재 상태: 백그라운드 연결을 시험하는 개발 브랜치.** 스토어에는 기존 0.4.0을 2026-10-07 제출했고 당시 심사 대기·미게시 상태와 승인 후 자동 공개 설정을 확인했습니다. 현재 승인·공개 상태는 다시 확인해야 합니다. 기존 DOM 설치본의 여러 턴·TXT·PNG → 세 서비스 → 원래 메인 최종 답변 수집은 과거 검증 기록에 남아 있으며, 아래 연결 시험의 성공을 뜻하지 않습니다. [검증 기록](docs/testing/validation.md)과 [출시 체크리스트](docs/release/release-checklist.md)를 참고하세요.

스토어 설치본은 Chrome의 자동 업데이트를 사용합니다. 확장 하단에서 설치 버전과 업데이트 안내를 확인할 수 있습니다. 압축해제 설치본은 새 빌드로 교체·새로고침해야 합니다. 업데이트는 세션 기록을 지우므로 필요한 결과를 먼저 **기록 저장**으로 내려받으세요. [업데이트 안내](docs/release/updates.md).

## 명령어 없이 설치하고 사용하기

1. 제공된 `multi-ai-checker-*-chrome.zip`을 내려받아 압축을 풉니다.
2. Chrome의 `chrome://extensions`에서 **개발자 모드 → 압축해제된 확장 프로그램을 로드합니다**를 선택하고 `manifest.json`이 있는 폴더를 고릅니다.
3. 확장의 **연결**에서 사용할 AI를 누릅니다. 탭이 열리면 필요한 경우 로그인하고 **로그인 완료 · 다시 확인**을 누릅니다.
4. 검토할 대화를 연 상태에서 **현재 탭에서 가져오기**로 대화를 읽고 불러온 질문·답변 쌍과 공유 내용을 확인합니다. 첫 실행에는 사이트 권한을 허용합니다.
5. 원본 대화에 파일·이미지가 있었다면 **파일 선택**에서 한 번에 모두 선택합니다. 검토할 다른 AI를 고릅니다. 파일 누락 여부를 확인한 뒤 **자동 검토 시작**을 누릅니다.

여러 턴의 대화 가져오기 → 다른 AI 답변 → 교차 검토 → 원래 메인 대화의 최종 답변까지 자동 진행합니다. 처음 사용하는 다른 AI에는 새 대화 탭을 열고, 미리 연결한 탭이 있으면 그 탭을 사용합니다. 각 AI 탭을 차례로 활성화하므로 패널은 열어두세요. 단계별 승인이나 복사·붙여넣기는 필요하지 않습니다. 오류가 생기면 이유를 표시하고 애매한 요청은 재전송하지 않습니다.

이 개발 브랜치의 **연결 → 백그라운드 연결 시험**은 Claude의 새 탭을 준비하고, 계정과 모델이 확인되면 별도 테스트 대화에 `Reply with CROSSCHECK_OK only.` 한 요청을 보내도록 구현했습니다. 새 탭은 활성화하지 않으며 브라우저가 같은 서비스 요청에 로그인 쿠키를 자동 부착합니다. 쿠키·토큰 값은 읽거나 확장 저장소·서버로 복사하지 않습니다. 이 실험은 짧은 텍스트만 다루며 기본 자동 검토의 탭 전환은 그대로입니다. ChatGPT·Gemini, 전체 대화·첨부·원래 메인 최종 반환의 새 방식은 아직 검증 중입니다. [실험 범위와 증거](docs/research/background-web-transport.md).

**현재 실계정 시험은 요청 전 모델 확인에서 멈춥니다.** 계정의 모델 목록 응답이 비어 있어 화면의 선택과 실제 요청 모델을 검증할 수 없습니다. 임의 모델을 대신 넣지 않았고 생성 요청·답변 완료는 확인하지 못했습니다. 단위·합성 검사의 통과와 별개인 실제 연결 차단 사항입니다.

**연결**에서 각 AI의 웹 모델 메뉴를 불러와 선택할 수 있습니다. 메뉴가 지원되지 않거나 선택지가 없는 계정은 웹에서 선택한 모델을 사용합니다. 검토 설정은 기본적으로 접혀 있습니다. 세 AI 기준 빠르게는 최대 4회, 꼼꼼하게는 최대 6회 요청하며 기존 메인 답변을 재사용합니다. 불러온 대화의 질문과 답변이 선택한 서비스에 공유되고 최종 프롬프트가 메인 대화에 보내진다는 안내를 시작 버튼 바로 아래에 표시합니다.

선택한 첨부 원본은 각 AI에 동일하게 업로드합니다. 업로드 완료를 확인하지 못하면 해당 AI에 질문을 보내지 않고 오류를 표시합니다. 최대 10개·합계 20 MB이며 각 사이트의 별도 파일 형식·사용량 제한이 적용됩니다. 원본은 패널 메모리에만 있으므로 패널을 다시 열어 계속하려면 같은 파일을 다시 선택해야 합니다. 연결 설정에서 탭을 열어도 이미 선택한 메인 대화는 바뀌지 않습니다.

**이전 버전에서 업데이트:** 새 ZIP의 폴더를 로드하거나 기존 설치 폴더를 교체한 뒤 확장 목록의 새로고침을 누릅니다. 기존에 주입된 스크립트를 갱신하도록 **AI 탭도 새로고침**합니다. 이전 검토는 자동 재개하지 않으므로 새 검토로 시작하세요.

웹 로그인은 같은 Chrome 프로필의 각 서비스 세션을 뜻합니다. 확장은 다른 프로필의 로그인에 접근하지 않고 계정 순환, 쿼타 우회, CAPTCHA 해결, 자동 재시도를 하지 않습니다. 구독/잔여 쿼타/모델/검색 기능은 해당 서비스가 결정합니다. 웹 자동화 허용 여부와 현재 약관은 배포 전 별도로 확인해야 합니다.

## 개발자용

Node.js 24, npm, Chromium. 사용자에게 이 절차를 요구하지 않습니다.

```bash
npm ci
npm run check                # 타입, 도메인/아키텍처 테스트, MV3 빌드
npm run test:e2e             # 실제 Chromium + 화면/DOM fixtures; 로그인 서비스 호출 없음
npm run test:e2e:extension   # 실제 unpacked 확장: 관리 정책이 없는 테스트 머신 필요
npm run zip                  # .output/*-chrome.zip
```

일반 개발 머신/CI에서는 `npx playwright install chromium`으로 테스트 브라우저를 준비합니다. 이미 설치된 브라우저는 `CHROMIUM_PATH`로 지정할 수 있습니다. 클라우드의 관리자 정책을 우회하거나 변경하지 마세요. [아키텍처](docs/architecture/overview.md), [실서비스 E2E](docs/testing/live-login.md), [개인정보 및 보안](docs/security/privacy.md), [오픈소스 조사](docs/research/references.md)를 참고하세요.

## 신뢰성의 범위

- 공유 범위는 사이트가 현재 페이지에 불러온 완료된 질문·답변 쌍입니다. 패널에서 전부 펼쳐볼 수 있습니다. 감지된 누락·불명확한 순서·미완성 답변·길이 초과는 가져오기를 막습니다. 아직 불러오지 않은 과거 대화까지 읽었다고 보장하지 않습니다.

- 여러 AI의 합의는 사실 검증이 아닙니다. 웹 검색과 1차 자료 확인을 프롬프트로 요청하지만, 실제 검색 실행이나 출처의 진위를 강제/보증하지 않습니다.
- DOM 어댑터는 사이트 변경에 영향을 받습니다. 입력란·전송 버튼·새 답변·완료 표시·질문 대응 관계를 확인할 수 없으면 수동 입력으로 전환합니다. 영어/한국어 표식을 우선 지원하며 다른 언어는 별도 검증이 필요합니다.
- 마지막 프롬프트는 가져온 메인 탭과 대화 주소를 고정합니다. 새로고침/탭 변경 시 재연결이 필요하며, 다른 대화로 보내지 않습니다.
- 비밀번호·쿠키·세션 토큰을 읽지 않습니다. 개발자 서버·분석 SDK·별도 개발자 API는 사용하지 않습니다. Claude 연결 시험은 Claude 페이지에서 같은 서비스의 내부 HTTP 경로를 호출합니다. 답변은 텍스트로 표시하고 외부 이미지·HTML을 실행하지 않습니다.
- 데이터는 Chrome 세션에만 저장합니다. AI 서비스에 보낸 대화와 직접 내려받은 파일은 그곳에 남습니다. [삭제 범위](docs/security/privacy.md)를 확인하세요.
