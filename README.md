# CrossCheck · Multi AI Checker

로그인한 ChatGPT·Claude·Gemini 웹 대화의 답변을 모아 검토하고, **원래 메인 대화에 재탐색·최종 종합 프롬프트를 보내는** Chrome 사이드패널 확장입니다. 사용자는 API 키, CLI, TUI 없이 웹 로그인과 확장 화면만 사용합니다.

> **현재 상태: 검증 중인 프로토타입.** 빌드·도메인 테스트·Chromium 기반 화면/DOM fixture 검증을 제공합니다. 실제 서비스의 로그인 계정 연동은 아직 검증하지 못했습니다. 클라우드 Chromium의 관리자 정책이 확장 설치를 막고, 네트워크 프록시가 세 서비스 접속을 거부합니다. 세부 범위는 [검증 기록](docs/testing/validation.md)에 구분했습니다.

## 명령어 없이 설치하고 사용하기

1. `multi-ai-checker-0.2.0-chrome.zip`을 내려받아 압축을 풉니다.
2. Chrome의 `chrome://extensions`에서 **개발자 모드 → 압축해제된 확장 프로그램을 로드합니다**를 선택하고 `manifest.json`이 있는 폴더를 고릅니다.
3. 같은 Chrome 프로필에서 사용할 AI 사이트에 평소처럼 로그인합니다.
4. 검토할 대화를 연 상태에서 확장을 누르고 **자동 검토 시작**을 누릅니다. 첫 실행에 선택한 사이트 권한을 허용합니다.

질문·답변 가져오기 → 다른 AI 답변 → 교차 검토 → 원래 메인 대화의 최종 답변까지 자동 진행합니다. 처음 사용하는 다른 AI에는 새 대화 탭을 열고, 미리 연결한 탭이 있으면 그 탭을 사용합니다. 패널은 열어두세요. 단계별 승인이나 복사·붙여넣기는 필요하지 않습니다. 오류가 생기면 이유를 표시하고 애매한 요청은 재전송하지 않습니다.

**연결**에서 각 AI의 웹 모델 메뉴를 불러와 선택할 수 있습니다. 메뉴가 지원되지 않거나 선택지가 없는 계정은 웹에서 선택한 모델을 사용합니다. 검토 설정은 기본적으로 접혀 있습니다. 세 AI 기준 빠르게는 최대 4회, 꼼꼼하게는 최대 6회 요청하며 기존 메인 답변을 재사용합니다. 질문과 답변이 선택한 서비스에 공유되고 최종 프롬프트가 메인 대화에 보내진다는 안내를 시작 버튼 바로 아래에 표시합니다.

**0.1.0에서 업데이트:** 새 ZIP의 폴더를 로드하거나 기존 설치 폴더를 교체한 뒤 확장 목록의 새로고침을 누릅니다. 기존에 주입된 스크립트를 갱신하도록 **AI 탭도 새로고침**합니다. 이전 검토는 자동 재개하지 않으므로 새 검토로 시작하세요.

웹 로그인은 같은 Chrome 프로필의 각 서비스 세션을 뜻합니다. 확장은 다른 프로필의 로그인에 접근하지 않고 계정 순환, 쿼타 우회, CAPTCHA 해결, 자동 재시도를 하지 않습니다. 구독/잔여 쿼타/모델/검색 기능은 해당 서비스가 결정합니다. 웹 자동화 허용 여부와 현재 약관은 배포 전 별도로 확인해야 합니다.

## 개발자용

Node.js 24, npm, Chromium. 사용자에게 이 절차를 요구하지 않습니다.

```bash
npm ci
npm run check                # 타입, 도메인/아키텍처 테스트, MV3 빌드
npm run test:e2e             # 실제 Chromium + 화면/DOM fixtures; 로그인 서비스 호출 없음
npm run test:e2e:extension   # 실제 unpacked 확장: 관리 정책이 없는 테스트 머신 필요
npm run zip                  # .output/*-chrome.zip
```

일반 개발 머신/CI에서는 `npx playwright install chromium`으로 테스트 브라우저를 준비합니다. 이미 설치된 브라우저는 `CHROMIUM_PATH`로 지정할 수 있습니다. 클라우드의 관리자 정책을 우회하거나 변경하지 마세요. [아키텍처](docs/architecture/overview.md), [실서비스 E2E](docs/testing/live-login.md), [개인정보 및 보안](docs/security/privacy.md), [오픈소스 조사](docs/research/references.md)를 참고하세요.

## 신뢰성의 범위

- 여러 AI의 합의는 사실 검증이 아닙니다. 웹 검색과 1차 자료 확인을 프롬프트로 요청하지만, 실제 검색 실행이나 출처의 진위를 강제/보증하지 않습니다.
- DOM 어댑터는 사이트 변경에 영향을 받습니다. 입력란·전송 버튼·새 답변·완료 표시·질문 대응 관계를 확인할 수 없으면 수동 입력으로 전환합니다. 영어/한국어 표식을 우선 지원하며 다른 언어는 별도 검증이 필요합니다.
- 마지막 프롬프트는 가져온 메인 탭과 대화 주소를 고정합니다. 새로고침/탭 변경 시 재연결이 필요하며, 다른 대화로 보내지 않습니다.
- 비밀번호·쿠키·세션 토큰을 읽지 않습니다. 서버/분석 SDK/외부 API 호출이 없습니다. 답변은 텍스트로 표시하고 외부 이미지·HTML을 실행하지 않습니다.
- 데이터는 Chrome 세션에만 저장합니다. AI 서비스에 보낸 대화와 직접 내려받은 파일은 그곳에 남습니다. [삭제 범위](docs/security/privacy.md)를 확인하세요.
