What the extension handles

CrossCheck reads the completed question-and-answer turns loaded in the AI conversation you choose. The panel shows the loaded scope and lets you inspect every shared turn before starting. A review shares those conversation turns, review prompts, evidence you enter, and original files you select with the participating services: OpenAI/ChatGPT, Anthropic/Claude, and Google/Gemini, according to your selection. The final synthesis request returns to your original main conversation.

It also handles the selected provider page's composer state and model menu, and keeps tab, document, and conversation references to target requests safely. It does not read passwords, cookies, login tokens, account-profile fields, or files you have not selected. Each website uses its own normal login session.

Where data is stored

Chrome session storage holds the imported conversation turns, review text, entered evidence, job status, provider bindings, and file metadata: name, MIME type, size, and a SHA-256 value used to match originals. Raw file bytes are not stored in review history. They are processed temporarily in the open panel's memory and in the destination website's upload flow. Closing or reloading the panel loses the selected originals from panel memory; continuing requires reselecting matching originals.

Disabling, reloading, or updating the extension, or restarting the browser, clears its session records and bindings. Export needed results before updating. Interrupted requests do not automatically restart.

Sharing and purpose

Data is used for the review workflow you start. CrossCheck operates no developer backend, analytics endpoint, advertising tracker, or telemetry service. The extension does not sell your data or use it for advertising, unrelated profiling, creditworthiness, or lending decisions.

CrossCheck's use and transfer of user data adhere to the Chrome Web Store User Data Policy, including its Limited Use requirements. Transfers to the AI services you select are limited to providing the review workflow disclosed here and in the extension.

Uploading a selected file already shares it with that AI service, even if a later message fails. Provider retention, training settings, and processing depend on the provider's policy and your account settings. CrossCheck does not change them. Review those services' privacy information before sharing sensitive content: OpenAI, Anthropic, and Google.

Your controls and deletion

You choose participating services and grant their site permissions. You can disconnect a provider or revoke access in Chrome. Clearing the review record removes that record from the extension; provider bindings remain until disconnected or the session is cleared. Diagnostic exports omit conversation text, URLs, account identifiers, and file contents.

These actions do not delete conversations or uploads already sent to AI services, or files you exported to your device. Delete those through the relevant service or your device. Do not email private conversations, credentials, or original files when requesting support.

This policy page and changes

This static policy page uses no scripts, analytics, or third-party embeds. It is hosted on GitHub Pages; GitHub handles hosting requests under its own privacy practices. We update this notice when the extension's data handling changes and show the effective date above.

처리하는 정보와 공유 대상

CrossCheck는 사용자가 선택한 AI 대화 페이지에 불러온 여러 턴의 질문과 완료된 답변을 읽습니다. 패널에서 불러온 범위와 각 질문·답변을 확인할 수 있습니다. 사용자가 검토를 시작하면 이 대화 맥락·검토 프롬프트·직접 입력한 근거·선택한 원본 파일을 참여 서비스(OpenAI/ChatGPT, Anthropic/Claude, Google/Gemini)에 보냅니다. 최종 종합 요청은 원래 메인 대화로 돌아갑니다. 정확한 전송을 위해 입력란·모델 메뉴 상태와 탭·문서·대화 참조도 처리합니다.

비밀번호·쿠키·로그인 토큰·계정 프로필·선택하지 않은 파일을 읽지 않습니다. 각 웹사이트의 일반 로그인 세션을 사용합니다. 개발자 서버·분석·광고·텔레메트리 전송은 없으며 데이터를 판매하거나 광고·관련 없는 프로파일링·신용 평가·대출 판단에 사용하지 않습니다.

CrossCheck의 사용자 데이터 사용 및 전송은 제한적 사용(Limited Use) 요건을 포함한 Chrome 웹 스토어 사용자 데이터 정책을 준수합니다. 선택한 AI 서비스로의 전송은 이 방침과 확장 화면에 고지한 검토 기능을 제공하는 데 한정됩니다.

저장·보관·삭제

Chrome 세션 저장소에 불러온 대화 맥락·검토 문장·근거·작업 상태·연결 참조와 파일 이름·형식·크기·원본 일치 확인용 SHA-256 값을 저장합니다. 파일 원본은 검토 기록에 저장하지 않고 열린 패널의 메모리와 대상 사이트의 업로드 과정에서 일시적으로 처리합니다. 패널을 다시 열어 계속하려면 같은 원본을 다시 선택해야 합니다.

확장 비활성화·새로고침·업데이트·브라우저 재시작 시 세션 기록과 연결이 지워집니다. 필요한 결과는 먼저 기록 저장으로 내보내세요. 중단된 요청은 자동으로 다시 시작하지 않습니다. 검토 기록 삭제는 그 기록을 지우며, 연결은 연결 해제 또는 세션 초기화 전까지 남습니다. 진단 내보내기에는 대화 문장·URL·계정 식별자·파일 내용이 포함되지 않습니다.

파일 업로드는 메시지 전송이 실패해도 해당 서비스와 파일을 공유한 것입니다. 서비스의 보관·학습·처리는 해당 개인정보처리방침과 계정 설정을 따릅니다. 확장 기록 삭제·연결 해제는 서비스에 이미 보낸 대화·업로드 파일이나 직접 내려받은 파일을 지우지 않습니다. 해당 서비스 또는 기기에서 따로 삭제하세요.

사용자의 선택과 문의

참여 AI와 원본 파일을 직접 선택하며, 연결 해제 또는 Chrome 사이트 권한 철회가 가능합니다. 문의 시 비밀번호·개인 대화·원본 파일을 이메일에 포함하지 마세요. 이 정적 안내 페이지에는 스크립트·분석 도구·외부 삽입 콘텐츠가 없으며 GitHub Pages에서 호스팅됩니다. 처리 방식이 바뀌면 이 문서와 시행일을 갱신합니다.
